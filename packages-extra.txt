# Pacotes extras da máquina de referência — NÃO são necessários para a

# É o que sobrou do 'paru -Qeq' depois do packages.txt: sistema base, hardware,
# toolchains, bancos e apps pessoais.
#
# As duas listas juntas não são mais o 'paru -Qeq' literal: pacotes que caíram
# em desuso foram tirados de propósito (o grupo xorg — só o xorg-xwayland

# extras e versões duplicadas de Python e JDK).

# Instalar com:  ./install.sh --extra
#         ou:    paru -S --needed $(sed -e 's/#.*//' -e '/^\s*$/d' packages-extra.txt)
#
# Os marcados com "AUR" não estão nos repositórios oficiais.
